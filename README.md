# lot-o-odds

A Clojure project for analyzing lottery odds.

## Lucky for Life - Prize Tiers and Odds

| Match | Prize | Odds |
|-------|-------|------|
| 5 + LB | $1,000 a day for life* | 1 in 30,821,472 |
| 5 of 5 | $25,000 a year for life* | 1 in 1,813,028 |
| 4 + LB | $5,000* | 1 in 143,356 |
| 4 of 5 | $200 | 1 in 8,433 |
| 3 + LB | $150 | 1 in 3,413 |
| 3 of 5 | $20 | 1 in 201 |
| 2 + LB | $25 | 1 in 250 |
| 2 | $3 | 1 in 15 |
| 1 + LB | $6 | 1 in 50 |
| LB | $4 | 1 in 32 |

*Note: Some prizes may have cash value options

## Usage

Run the REPL:
```bash
clojure -M:repl
```

Run tests:
```bash
clojure -M:test
```
